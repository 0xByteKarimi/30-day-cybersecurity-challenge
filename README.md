> **Build real cyber skills in 30 days.**

A daily, self-paced challenge for entry- to associate-level learners and Cisco certification holders. Each day pairs **~20–60 minutes of learning** with a **hands-on or reflection task**.

## 🎯 How It Works

**Learn → Do → Log.** Read/watch the resource, complete the task, and mark each completed day in your streak tracker.

- **Beginners:** Stop at the core task.
- **Certification holders:** Do the ⚡ **Stretch** items.
- **Time commitment:** 20–60 minutes per day.

## 📅 Challenge Overview

| Week | Theme | Focus |
|------|-------|-------|
| [Week 1](week-1-security-foundations/) | Security Foundations | Think like a defender |
| [Week 2](week-2-network-endpoint-defense/) | Network & Endpoint Defense | Protect what attackers target first |
| [Week 3](week-3-security-operations/) | Security Operations & Threat Detection | Think like a SOC analyst |
| [Week 4](week-4-offense-cloud-certification/) | Offense, Cloud & Certification | Think like an attacker |
| [Week 5](week-5-capstone-next-steps/) | Capstone & Next Steps | Apply everything you've learned |
