## 🎃 About This Challenge

This challenge was offered by **Cisco** for **Cybersecurity Awareness Month (October)**.

Each day pairs **20–60 minutes of learning** with a hands-on or reflection task. The goal is simple: build a real foundation in cybersecurity, one day at a time.

> **Learn → Do → Log.**
> Read or watch the resource, complete the task, and mark the day as done.

---

## 🎯 Who This Is For

- **Beginners** — start with the core task each day
- **Cisco certification holders** — take on the ⚡ **Stretch** items for deeper practice
- **Anyone curious** — if you can spare 30 minutes a day, you can do this

No prior experience required.

## 🚀 How to Start

1. **Pick a day** — start with [Day 1](week-1-security-foundations/day-01-why-cybersecurity-matters.md)
2. **Read the resource** — usually 20–30 minutes
3. **Do the task** — hands-on or reflection
4. **Log it** — write your notes in the day file
5. **Commit with `Day X`** — your progress tracker updates automatically
6. **Move to the next day**

That is it. One day at a time.
