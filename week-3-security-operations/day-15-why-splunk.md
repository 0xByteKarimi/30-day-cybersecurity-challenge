## 📚 Learned

I read about why learning Splunk is a valuable skill for a career in cybersecurity.

What I learned:
- **Splunk** is a tool used to search, monitor, and analyze machine data.
- It takes data from many sources — firewalls, endpoints, cloud services, and applications — and puts it in one place.
- Security teams use it to detect threats, investigate incidents, and build dashboards.
- Knowing Splunk is in high demand because almost every large organization uses some form of log analysis.

🔗 [Why You Should Learn Splunk in 2026](https://www.splunk.com)

---

## ✅ What I Did

I explored the main reasons Splunk skills matter:

1. **It brings data together** — no more jumping between 10 different dashboards.
2. **It helps detect threats** — searches can spot patterns humans would miss.
3. **It is used everywhere** — banks, hospitals, tech companies, governments.
4. **It leads to jobs** — SOC analyst, threat hunter, security engineer roles often list Splunk as a requirement.

---

## 💡 Key Takeaways

- Splunk is not just a tool. It is a way of working with data.
- Logs are useless if you cannot search them quickly.
- Learning one SIEM (like Splunk) makes learning others easier.
- Data skills are becoming as important as network skills in security.
